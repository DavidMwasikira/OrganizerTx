ORGANIZERTX - setting it up (no coding; about 20 minutes the first time)

The folder has two parts:
  the app      index.html, config.js, sw.js, manifest.webmanifest, icons
  the server   server/worker.js  (holds your Anthropic key and checks access codes)

NEVER put your Anthropic key in the app files, in WhatsApp, or in any chat.
It goes in one place only: the server's secret settings (step A3).

------------------------------------------------------------------
QUICK TEST, JUST YOU (no server needed)
------------------------------------------------------------------
1. Leave config.js as it is.
2. Go to https://app.netlify.com/drop (free account) and drag the "organizertx"
   folder onto the page. You get a web address.
3. Open the address, paste your own key on the first screen. It stays on your
   device. Do not share this version's key with anyone.

------------------------------------------------------------------
A. THE SERVER (Cloudflare Workers, free plan)
------------------------------------------------------------------
Menu names on Cloudflare change from time to time; look for the nearest match.
A1. Create a free account at https://dash.cloudflare.com
A2. Workers & Pages > Create > Worker. Name it "organizertx". Deploy, then
    "Edit code": delete what is there, paste everything from server/worker.js,
    and Deploy again.
A3. In the Worker: Settings > Variables and Secrets. Add:
      ANTHROPIC_API_KEY   (type Secret)  your key from console.anthropic.com
      SLOTS               (type Secret)  MU96-7KQ2=David, MU96-X4P9=Wanjiru
      DAILY_LIMIT         (type Text)    40
A4. Daily cap (recommended): Storage & Databases > KV > create a namespace
    called "organizertx-usage". Back in the Worker: Settings > Bindings > add a
    KV namespace binding, variable name USAGE, pointing to that namespace.
    Without this step there is no per-person daily limit.
A5. Copy the Worker's address (it ends in .workers.dev).

------------------------------------------------------------------
B. THE APP
------------------------------------------------------------------
B1. Open config.js in Notepad and put the Worker address between the quotes:
      window.ORGANIZERTX_SERVER = "https://organizertx.your-name.workers.dev";
B2. Drag the "organizertx" folder onto https://app.netlify.com/drop again.
B3. Optional, safer: add ALLOWED_ORIGIN (type Text) to the Worker settings,
    set to your app's address, so no other website can use your server.
B4. Share the app address in the group. On Android: Chrome menu (three dots)
    > "Install app" or "Add to Home screen".

------------------------------------------------------------------
C. SELLING AND MANAGING SLOTS
------------------------------------------------------------------
- A slot is one line in SLOTS: CODE=Name. Make codes hard to guess.
- New paying user: add a pair to SLOTS and save. Send them the code privately.
- Someone stops paying: remove their pair and save. Their app stops working.
- One code per person. A shared code shares one daily limit.
- DAILY_LIMIT counts requests per code per day. One research, one update or
  one chat message is one request (a long deep research can be two or three).

------------------------------------------------------------------
WHAT USERS SET UP
------------------------------------------------------------------
- Name, country and (optional) town. Research is then based on that country,
  with amounts in the local currency and the US dollar equivalent.
- Explanation level: ELI5, ELI10, ELI15, Standard or Expert.
- Folders > Guides holds two ranked lists built for the user's country:
  "Best 10 AI businesses to start in 2026" and "Best AI stack to use".
  Opening an entry prepares a timeline (Gantt chart) and an activity plan.
  Each list and each plan uses one request the first time; after that it is
  kept on the device until the user refreshes it.
- Home: an ask box for research, a Create button, today's tasks, quick links
  (pin your own) and the latest updates.
- "Week NN: 10 best business ideas" on Home refreshes once a day at a time
  the user sets in Settings (07:00 by default). That is one request per user
  per day. If the app is closed at that time, it refreshes when next opened;
  the last list stays on screen meanwhile.
- Tasks: a board with four lanes (Not started, In progress, Blocked,
  Complete) and a list view. Drag cards between lanes on a computer; on a
  phone, open the card and change its status. Tasks have a project, due
  date and notes.
- Projects: create your own and let OrganizerTX draft the activity plan and
  timeline, or add tasks by hand. "My tasks" holds day-to-day items.
- Dashboard shows My Action List: every plan the user added, with progress
  bars and percentages, plus every discussion with its start date.
- Reports include flow charts and block diagrams, photos with their source
  (from Wikimedia Commons), tables, and a short explanation under each.
  Diagrams and photos need an internet connection to appear.

------------------------------------------------------------------
E. EMAIL (optional; needs the server from section A)
------------------------------------------------------------------
E1. Create a free account at https://www.brevo.com and verify the address
    you want the emails to come from (Senders).
E2. In Brevo: SMTP & API > API Keys > create a key.
E3. In the Worker settings add:
      BREVO_API_KEY   (type Secret)  the key from E2
      SENDER_EMAIL    (type Text)    the verified address from E1
E4. Replace the Worker code with the server/worker.js from this version.
Each user then types their own email address in Settings, and every new list
of weekly AI business ideas is emailed to them (at most 3 emails per code per
day). Without the server, "Email this list" opens a ready-made draft in the
user's own mail app instead, and they press Send themselves.

------------------------------------------------------------------
D. PROTECT YOURSELF
------------------------------------------------------------------
- In the Claude Console, set a monthly spend limit on your account before
  giving out any codes. That is your hard ceiling.
- Web search must be switched on in the Claude Console (Settings > Privacy).
- Watch the Console's usage page for the first weeks to learn what a typical
  user costs you before fixing the slot price.
- You are the account holder: what users do with their codes runs under your
  Anthropic account and its usage rules.
